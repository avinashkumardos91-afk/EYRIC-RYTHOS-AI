# Interview Questions for Senior Frontend Engineer

## Technical & Hard Skills
1. **React & Ecosystem**: Can you walk me through your approach to managing state in a complex React application? When would you choose Context API versus a library like Redux or Zustand?
2. **Performance Optimization**: Tell me about a time you had to diagnose and fix a significant performance bottleneck in a web application. What tools did you use and what was the outcome?
3. **Architecture**: If you were tasked with building our new web application from scratch today, how would you structure the frontend architecture and why?
4. **API Integration**: How do you handle complex API integrations, specifically those that might have high latency or stream data (e.g., typical AI model responses)?
5. **Testing & Quality**: Describe your ideal frontend testing strategy. How do you balance unit, integration, and end-to-end tests to ensure high confidence without slowing down deployment?

## Behavioral & Cultural Fit
1. **Leadership & Mentorship**: Tell me about a time you mentored a junior engineer. How did you adapt your communication style, and what was the result?
2. **Conflict Resolution**: Describe a situation where you strongly disagreed with a product manager or designer on a feature implementation. How did you resolve the disagreement?
3. **Adaptability**: In a fast-paced startup, priorities often shift. Can you share an example of a time you had to pivot your technical approach midway through a project?
4. **Initiative**: Tell me about a time you identified a technical debt or process issue and took it upon yourself to fix it.

## Scenario-Based Problem Solving
1. **The Real-Time AI Dashboard Scenario**: We need to build a real-time dashboard that displays streaming text output from an AI model while also rendering dynamic charts based on the extracted data. The data comes in via WebSockets. Walk me through how you would architect this page. How would you handle potential memory leaks or rendering bottlenecks as the data volume grows over a long session?
